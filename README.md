# 🌦️ Weatherly – React Weather App

Weatherly is a modern weather application built with **React.js and Vite** that helps users explore weather information through a clean and user-friendly interface.

The project was developed to practise modern frontend development, React components, API integration, responsive design, and real-world application testing.

## ✨ Features

- 🌤️ Weather information interface
- 🌍 Search weather by city
- 📱 Responsive user interface
- 🌡️ Weather details and conditions
- ⚡ Fast performance powered by Vite
- 🎨 Modern and user-friendly design

## 🛠️ Technologies Used

## 💻 Run Locally

Follow these steps to run Weatherly on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/sheri/Weatherly.git
```

### 2. Navigate to the project folder

```bash
cd Weatherly
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🏗️ Production Build

To create an optimised production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
